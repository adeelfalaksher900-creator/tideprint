# Contributing

Open a focused issue or pull request explaining the coastal-data problem and the resulting behaviour. Keep unrelated changes out. Use Node 24, run `npm ci --ignore-scripts`, `npm test`, `npm run build` and `npm audit` before opening a pull request. Changes to receipt encoding, QA or proof parsing need meaningful regression cases and an explicit algorithm/schema compatibility decision. Never add private datasets or credentials.

Preserve source attribution and distinguish measurements from deliberately changed fixtures. Do not claim detection accuracy without an appropriate independent dataset and evaluation. Do not weaken verification to make a proof or receipt pass.
