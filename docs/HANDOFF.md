## Product boundaries

CSV: 1 MiB, 3,000 rows, six-minute profile, UTC, metres and declared datum. Workspace: 30 items, local browser storage, 32 MiB backup input limit; no cloud accounts or sync. Reviewer labels are self-declared. The seal supports integrity against a trusted digest, not data accuracy or authorship. Bitcoin path/header checks rely on Blockstream's chain view; use a full-node verifier for stronger independence. There is no global API quota, service-level guarantee or QARTOD certification.
